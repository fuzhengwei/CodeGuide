# 《WaLiOffice - AI Agent 智能办公平台》第5-2节：云服务器部署配置

作者：小傅哥
<br/>博客：[https://bugstack.cn](https://bugstack.cn)

>沉淀、分享、成长，让自己和他人都能有所收获！😄

大家好，我是技术UP主小傅哥。

上一节我们把 WaLiOffice 打包成了 Docker 镜像，这节我们把它部署到**云服务器**上，让用户通过互联网访问（可以在这一节自己重新打包最新镜像）。

1. **快捷部署**，使用 WaLiCode AI 编程助手，通过对话式交互直接把服务部署到云服务器；我已经准备了一个打包好的镜像，你可以快速体验。
2. **自己构建**，手动完成配置、上传、启动的完整流程。学完这节，你的 WaLiOffice 就有了一个真正可以对外服务的地址。

## 一、本章诉求

1. **云服务器环境配置**：安装 Docker、开放安全组端口、准备部署目录
2. **快捷部署**：使用 WaLiCode 等 AI 编程助手，通过对话直接完成「改配置 → 传文件 → 拉镜像 → 启动 → 验证」全流程
3. **自己构建部署**：手动修改 docker-compose 配置、上传服务器、启动服务，理解每一步在做什么
4. **访问验证**：容器健康检查、HTTP 探活、日志排查
