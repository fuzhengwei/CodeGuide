## 一、产品功能

**AI Agent 通识教程**，短期帮你提高面试能力，长期教你如何构建智能体。因为这些东西，都来自于真实的项目实战后，做的提炼总结。学习起来会真实感受到这些东西怎么做，而不会有空洞感。

就像；`上下文怎么裁剪`、`工具怎么调准`、`ReAct 何时跑何时停`、`记忆到底存什么`、`消息结构怎么设计才命中缓存`。干过智能体的面试官，几句从实际场景出发的问题，就能把小白问住。所以，如果你是希望充实 AI Agent 开发的伙伴，那么这套教程非常有必要刷一下。

### 1. 📚 课程内容

<div align="center">
    <img src="https://bugstack.cn/images/article/ai/ai-agent-guide-wx-05.png" width="650px">
</div>

- 完整 Agent 知识体系：大模型基础 → 提示词/上下文工程 → ReAct → 记忆系统 → Function Calling / MCP / Skills → RAG → 多 Agent 与 A2A → LangGraph → 评估安全部署，一站式学完
- 有白色/黑色主题，可以朗读内容、调整字体。核心概念配流程图解，不用啃大段文字，还可以把你需要的重点，长按收藏为段落笔记。

### 2. 🎯 面试考察

<div align="center">
    <img src="https://bugstack.cn/images/article/ai/ai-agent-guide-wx-06.png" width="850px">
</div>

- **逐章面试**：30 章教程题库共 508 道题，按章检验掌握度，支持通关进度与正确率统计
- **4 种面试官风格**：🔥 犀利施压（还原大厂压力面）、🌸 温柔引导（适合初学者）、💼 大厂实战（只聊能上线的方案）、📐 稳重基础（抠概念准确性）
- **大厂真题**：字节跳动、美团、京东真题各 10 道，还原真实面试官提问节奏
- **混合面试**：多章随机抽题，模拟综合面
- **🎧 语音讲解**：老师念题 + 同学讲解，支持续听，通勤路上戴耳机就能刷面试题

### 3. 🪜 学习排行

## 二、实战项目

随着对 AI Agent 的理解加深，加下来就是项目实战了。

AI Agent 通识教程，来自于实战项目的提炼。这里小傅哥也为大家准备了完整的实战项目；你可以刷到 AI 八股，也可以学会 AI VibeCoding 编程，还能实践各类 AI 项目。如，市面的 AI IDE（walissh、walicode）教你做一套市面上的 trae.ai/qcoder 一样的编程工具。WaLiAPI（LLM 负载、日志审计、RAG 知识库）、AI MCP Gateway 教你如何构建 AI Infra 基础设施。还有 DSH Java，快速对接业务场景，也能做出 XxxBuddy 类产品。

<div align="center">
    <img src="https://bugstack.cn/images/article/project/ai-agent-scaffold/part-1/1-1/images/ai-agent-scaffold-1-1-10.png" width="850px">
</div>
综上，路线总图，表面看是项目。其实我是带着你做方案；

1. 最上面是基础的 AI 认知和 VibeCoding 入门，紧接着是非 Agent 的 AI 实战，如；OpenAI 代码自动评审、OpenAI 应用。紧接着是 Agent 基础设施 WaLiAPI（LLM Gateway）、AI MCP Gateway
2. 紧接着是3套技术架构方案，第一套拖拉拽类似 Dify 的简单版，做个 Agent 入门，了解关于 Agent 基础设计。之后是脚手架方案，通过 Spring AI、Google ADK 封装通用脚手架组件，之后来实现不同类型场景的项目。有脚手架可以快速开发。现在正在搞的是 Harness 马具插件方案，也就是说，提供一套核心 Agent 运行时，之后其他场景的对接，只是插件的开发实现。对接业务类场景效率非常高。
3. 右侧，是业务类 toc 项目，以及 API Gateway 网关场景。当你做的多了就会知道，即使做 Agent 你也离不开业务技术的储备。
