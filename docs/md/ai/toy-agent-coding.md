## 二、能学到啥 🤔

该项目是 AI Agent 场景的核心技术体系，以真实可运行为目标，通过 26 个渐进式案例，进行系统的需求分析、架构设计、功能实现，过程涵盖设计模式的运用，解决复杂场景问题。整套东西学习下来，你会感受到 AI Agent 不难，虽然知识点不少，但还挺好上手。

- 【基础】理解「智能体 = 模型 + 策略」：从一个 chat 方法起步，把用户的话交给模型、把模型的话还给用户，破除智能体的神秘感。
- 【基础】掌握系统提示词的三层结构：角色、背景、任务与约束，同一个模型换一份提示词就换一种人格，提示词是杠杆。
- 【核心】掌握 ReAct 循环：让模型学会边想边做，按思考 → 行动 → 观察结果 → 再思考迭代推进，直到给出最终答案，这是所有智能体框架的内核。
- 【核心】掌握工具调用（Function Calling）：声明工具清单、模型返回结构化调用请求、执行工具并回填结果，生产中 tools/tool_calls 与 MCP 协议本质都是这三步。
- 【核心】掌握上下文工程：用滑动窗口与摘要压缩管理短期记忆，控制上下文预算，让对话有来有回。
- 【架构】掌握意图路由：先让模型识别意图输出分类，再由决策中枢把请求路由到不同处理器，是多智能体编排的前置能力。
- 【架构】掌握 RAG 检索增强生成：切分 → 向量化 → 相似检索 → 增强生成，接入私有知识，回答有出处、知识可热更。
- 【架构】掌握知识编译与沉淀：把项目知识编译成结构化 Wiki 条目持久保存、增量维护，编译一次、持续复用。
- 【架构】掌握 MCP 工具标准化协议：工具侧拆成独立服务，通过标准的发现与调用方法实现工具与智能体彻底解耦。
- 【架构】掌握技能分层设计：从纯提示词模板到工具组合再到完整子流程，形成可沉淀、可复用的能力包。
- 【架构】掌握工具注册表模式：工具抽象成统一协议，注册即生效、注销即消失，执行器不认识任何具体工具。
- 【编排】掌握多智能体协作：规划者拆解任务、专家各司其职、审查员质量把关、主持者汇总交付，协作的本质是结构化消息在角色间流动。
- 【编排】掌握子代理派遣：主代理动态委托带独立上下文的分身执行子任务，可无状态新建、也可继承父会话继续话题。
- 【编排】掌握 A2A 跨进程协作协议：靠代理名片发现、标准化请求信封与异步回执对接外部代理。
- 【编排】掌握生产级运行时外壳：输入守卫防提示注入、最大步数保险丝防死循环、输出守卫做合规过滤、异常兜底，模型负责聪明、运行时负责可靠。
- 【编排】掌握工作流状态机编排：用节点、条件边与状态传递实现确定性流程，平衡可控性与灵活性。
- 【工程】掌握人机协同：关键信息缺失时会话挂起等待人工答复，用户下一条消息作为答复回填后继续执行。
- 【工程】掌握审批门禁：工具按风险分级，高危操作必须过人工审批，支持免审记忆，超时默认拒绝——宁可不执行，不可乱执行。
- 【工程】掌握沙箱纵深防御：策略层、内容黑名单、空间边界、路径规范化四层管线，任何一层拦截即生效。
- 【可靠】掌握事件溯源：会话即日志、日志即状态，服务重启后从日志完整重建上下文，天然获得审计与回放能力。
- 【可靠】掌握插件机制：把一批工具打包成可安装可卸载的插件，契约 SPI、隔离加载、生命周期完整。
- 【可靠】掌握 Hooks 钩子体系：把审计、脱敏、风控等横切逻辑挂在工具执行前后，挂钩即生效、摘钩即消失，工具作者无感知。
- 【终端】掌握 CLI 智能体：把智能体装进终端 REPL，工作目录即上下文，支持交互式与非交互两种模式。
- 【终端】掌握定时任务能力：把「什么时候做」也变成模型的决策对象，一次性调度、循环调度与任务管理，是提醒、巡检类智能体的雏形。
- 【设计】贯穿全程的通用思想：协议优先先用接口定契约、注册表统一管理注册与回收、策略层与骨架分离、append-only 事件流让状态可回放、纵深防御让安全成为多层管线。

此外，小傅哥已对全过程都做了需求的分析、功能的设计、编码的精细化处理，让你吃上细糠！也通过这种方式，真正的把你的技术储备整起来，以后进入到公司都是嘎嘎强的选手！

## 四、课程设计 📅

**我要想办法怎么让你把这个东西学会。**

这是我在设计整套课程时，想得最多的一个问题。以为看懂和真正会用之间，隔着一道大坎；很多人收藏了几十篇 Agent 文章、下载过好些个开源项目，真到自己动手时，连一个 `chat` 方法都写不出来。

所以这套课程没有平铺 26 个孤立的 demo，而是设计成了一条**打怪升级**的进阶路线——五个阶段，从一个 `chat` 方法打到生产级智能体，每个阶段都只解决一个核心矛盾，案例层层咬合：**阶段一的 `ChatModel` 抽象是后面 25 个场景的地基，阶段二的 ReAct 循环是所有编排场景的内核，阶段三的工具注册表撑起了阶段五的插件机制**。你每学一个新场景，用的都是前面亲手写过的东西。

每个阶段配齐三件套：**架构图**（先看清全貌再动手）、**知识表格**（每个 Step 讲什么、你能收获什么）、**课后练习**（改代码、造工具、做对比，把知识焊死在自己手里）。全程视频带着你一行行写，横向对比 `Java`、`Go`、`Python`、`TypeScript`、`JavaScript` 五种语言的实现，一套学完，各个语言的智能体开发都能看懂上手。

| 25   | CLI 终端   | REPL 交互 + `-p` 单命令模式                       | 形态是壳，灵魂仍是 `chat(input)`       |
| 26   | 定时任务     | 一次性/周期性调度、任务列表/取消                          | 让智能体从「被动应答」走向「主动服务」           |
